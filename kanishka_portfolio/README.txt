# Kanishka Koushal — Portfolio

## Run the website
1. Extract the ZIP folder.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Keep `index.html`, `style.css`, `script.js` and `profile.jpg` in the same folder.

## Personalise before submission
- Add your portrait and name it `profile.jpg`.
- Email, GitHub and LinkedIn links have already been added.
- Replace the sample GitHub project links with your repositories.
- Add your 10th and 12th school names, qualifications and passing years if required.
- Add a real resume PDF and link the "Download Resume" button if your teacher expects one. (This version uses an "Explore my work" button instead.)

## Files
- `index.html` — page content and sections
- `style.css` — layout, colours, responsive design and animations
- `script.js` — mobile menu, active navigation, reveal effects and current year
